# Beagle (web)

NEXAFS analysis software for the PAL 4D / 10A2 beamlines, web version.

**Run: <https://whiang.github.io/Beagle/>** — everything is calculated in the browser; no data leaves your computer.

> Park et al., *J. Synchrotron Rad.* **31**(1) (2024). [doi:10.1107/S1600577523008755](https://doi.org/10.1107/S1600577523008755) · <https://sites.google.com/view/beagle>
